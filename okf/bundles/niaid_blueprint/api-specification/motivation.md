NIAID repositories vary widely in metadata access capabilities. Aligning to a common standard would maximize metadata findability across research areas.

See also: [Requirements](/api-specification/requirements.md).

# Atomic concepts

| # | Concept | Lines |
|---|---------|-------|
| 118 | The NIAID repository landscape includes a variety of data systems supporting metadata access for researchers or their tools. | 180 |
| 119 | These systems range from those with little or no metadata access to those with Application Programming Interfaces (APIs) and other computational tools. | 180 |
| 120 | Although systems do not need to be the same to work together, aligning NIAID repositories to a common standard will maximize the findability of metadata from all research areas to support data discovery and reuse. | 180 |
