Repository owners should provide PID-integrated, consistent citation guidance for original and reused data in standard publication formats. Table 3 illustrates dataset and software citation examples across APA, MLA, and Chicago styles.[^blueprint-v2]

See also: [Requirements](/persistent-identifiers/requirements.md).

# Atomic concepts

|---|---------|-------|
| 157 | To enhance the citation process, data repository owners should include citation guidance for data generators. | 219 |
| 158 | Integrate PIDs into Citation: encourage use of PIDs, such as resolvable DOIs, in citations to enhance discoverability and traceability of digital objects (Table 3). | 221 |
| 159 | Establish Consistent Citation Guidelines: provide clear, consistent instructions for citing both original research data and reused data. | 223 |
