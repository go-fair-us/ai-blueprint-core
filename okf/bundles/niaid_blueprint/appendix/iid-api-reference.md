The API Reference appendix defines APIs as inter-system communication protocols and lists Supplemental Table 6 resources providing programmatic access to IID research data.

See also: [Requirements](/api-specification/requirements.md).

# Atomic concepts

| # | Concept | Lines |
|---|---------|-------|
| 223 | An API is a specified set of protocols and data standards that establish the ground rules by which one information system directly communicates with another. | 402 |
| 224 | Supplemental Table 6 catalogs Application Programming Interfaces for accessing research data in infectious and immune diseases. | 404 |
| 225 | The NIAID Data Ecosystem Discovery Portal API provides programmatic access to NIAID-funded research data, facilitating discovery and integration of IID data. | 408 |
| 226 | The TB Portals API provides programmatic access to TB-related data, including clinical, radiological, and genomic information. | 409 |
| 227 | The IEDB API provides programmatic access to a comprehensive collection of experimentally characterized immune epitopes. | 410 |
| 228 | ImmPort provides access to a wide range of immunology data, including data generated by NIAID-funded studies. | 411 |
| 229 | The GEO API provides access to high-throughput gene expression data relevant for immunology and infectious disease research. | 412 |
| 230 | The GenBank API provides access to genetic sequence data crucial for IID research. | 413 |
| 231 | The PDB API provides access to 3D structural data of proteins and nucleic acids important for understanding pathogens and immune responses. | 414 |
| 232 | The VEuPathDB API provides access to data on invertebrate vectors of human pathogens and other eukaryotic pathogens. | 415 |
| 233 | The FHIR API is a standard describing data formats and elements for exchanging electronic health records. | 416 |
| 234 | Additional listed APIs include PubChem PUG REST, OHDSI WebAPI, NCBI E-utilities, ClinicalTrials.gov, OpenFDA, BioMart, UMLS, ATLAS, BioSample, and CDC WONDER. | 417-428 |
