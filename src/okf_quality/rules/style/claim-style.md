# Claim / atomic style guidance

## Prefer

- One idea per atomic row (already structural)  
- Active voice  
- Blueprint terminology unchanged (DOI, ORCID, ROR, …)  
- Explicit modality: required / recommended / optional  

## Avoid

- Marketing adjectives (seamless, robust, cutting-edge, …)  
- Upgrading “may” / “should” to “must” without source support  
- Claims without line citations  

## Machine assist

Use STE skill `/ste-writing` on draft atomics; keep table structure intact.
