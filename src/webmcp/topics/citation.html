Citation guidance

Repository owners should publish clear, PID-based citation examples for original data and for reused data.

Citation gives credit, records provenance, and lets a repository see how its objects are reused. Practices still vary widely. Guidance should sit where depositors and reusers will find it, and it should include PIDs such as DOIs, ORCIDs, and repository RRIDs.

What to include

  • Original data: repository name, repository PID (for example an RRID), and the object PID, in text suitable for a paper.
  • Reused data: the object PID and, when useful, a repository accession.
  • Styles: copy-ready examples in common formats (APA, MLA, Chicago, NLM, PubMed).

Granularity should match how people actually use the resource. If they pull a few discrete objects, cite each object. If they query across the whole collection, a repository-level citation may be the better default.
