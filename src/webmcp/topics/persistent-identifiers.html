Persistent identifiers

Globally unique, persistently resolvable identifiers keep objects, people, and organizations findable when locations change.

FAIR asks for GUPRIs: globally unique, persistently resolvable identifiers. A DOI in its bare form (10.1000/182) is not resolvable. Prefix it: https://doi.org/10.1000/182. That resolvable form is the default for the object identifier field.

Ordinary URLs are globally unique and resolvable, but they last only as long as the host stays committed. That is why a resolvable DOI is the default object identifier. If a repository cannot mint DOIs, depositors can still register objects with Crossref or DataCite.
