APIs and machine access

Repositories do not need identical APIs. They do need a common way to retrieve the minimum metadata.

NIAID systems range from sites with almost no machine access to stacks with full query APIs. Alignment on a small access pattern makes metadata findable across those differences.

    When a full API is not feasible

      HTML-embedded metadata and an object server are alternative ways to reach the same resource, not two simultaneous pipes. In practice an API may return one object or many, each with a data stream and a metadata stream.
