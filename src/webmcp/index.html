NIAID Blueprint handbook

A short set of web pages about the NIAID Blueprint for Digital Objects. Humans can read them. A WebMCP-capable browser can call tools that search, look up, and navigate the same material.

The Blueprint is a FAIR program from NIAID/ODSET. It gives NIAID-funded repositories a minimum shared path for metadata, persistent identifiers, machine access, citation, and outreach, so digital objects can feed the NIAID Data Ecosystem Discovery Portal.

Three goals

  • Align repositories under a shared framework without forcing identical software stacks.
  • Capture structured metadata when data are created and deposited, not after the fact.
  • Stay flexible enough to plug into the wider NIAID ecosystem, including the Discovery Portal.

Topic pages

Prefer a conversation? Ask the Blueprint searches these pages and writes a short answer with links to the full guidance. It does not show the tool tester.

What this site is for

These pages are a test fixture for Chrome WebMCP (document.modelContext). Every page registers list_topics, search_topics, get_topic, and navigate_to_topic. Topic pages add extra tools for metadata elements, identifier schemes, API objectives, and citation formatting.

Use the tester below, or the Model Context Tool Inspector extension, after enabling chrome://flags/#enable-webmcp-testing.
