# NIAID Blueprint Prompt Library

High-quality, ready-to-use LLM prompts organized by the areas of the NIAID
Blueprint. Each concept file is a single prompt; each subdirectory is a category.

## Categories

* [metadata-schema](metadata-schema/index.md) - Guidance and prompts for capturing the minimal set of metadata elements recommended by the Blueprint.
* [persistent-identifiers](persistent-identifiers/index.md) - Guidance on using globally unique, persistent, machine-resolvable identifiers for digital objects and metadata.
* [apis-metadata-exposure](apis-metadata-exposure/index.md) - Exposing metadata through standard, open APIs so machines can discover and use NIAID-funded digital objects.
* [citation-outreach](citation-outreach/index.md) - Proper citation practices and establishing points of contact for training and support.
