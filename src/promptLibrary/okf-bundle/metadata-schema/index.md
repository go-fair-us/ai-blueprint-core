# NIAID Minimal Metadata Schema

Guidance and prompts for capturing the minimal set of metadata elements
recommended by the Blueprint.

## Subdirectories

* [core-elements](core-elements/index.md) - Basic metadata that applies to almost every digital object (name, description, dates, type, identifier).
* [attribution-provenance](attribution-provenance/index.md) - Author, funder, grant, and date information.
* [domain-specific](domain-specific/index.md) - infectiousAgent, host, healthCondition, and measurementTechnique.
