# Core Descriptive Elements

Basic metadata that applies to almost every digital object (name, description,
dates, type, identifier).

## Prompts

* [name-description](name-description.md) - Generates a concise, informative title and rich description that follows NIAID Blueprint recommendations and improves discoverability in the NIAID Data Ecosystem Discovery Portal.
* [identifier](identifier.md) - Helps choose the right type of persistent identifier (DOI, accession number, etc.) and explains how to record it according to the NIAID Blueprint.
