Overall

The API is machine-documented (Swagger 2.0) and retrieval uses GET, so two Section 3 objectives are met. The highest-priority gap is metadata encoding: responses are declared as JSON or text, not JSON-LD, so a catalog cannot treat these URLs as linked metadata. Fix that before the path cleanup (search, get_object, and /v1/). The practice gaps (license, examples, errors, pagination) matter for clients, but they are not Blueprint misses. A landing-page JSON-LD check, if wanted, is niaid-bp-metadata-extract — this run did not look for HTML-embedded metadata.
